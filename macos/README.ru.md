# Виды и обои для macOS

Русский · [English](README.md)

Игровые пейзажи «Школы Империи» на рабочем столе Mac и в хранителе экрана.
Приложение получает коллекции с [сайта проекта](https://games.oopssre.ru/),
меняет обои по расписанию или погоде и позволяет просматривать скачанные кадры.

## Возможности

- Обои дня, обычные коллекции, смена по дням, месяцам и сезонам.
- Серверная погода, игровой мир и погода выбранного города Open-Meteo.
- Общий профиль всех мониторов или отдельные настройки каждого экрана.
- Скачивание коллекций для работы без сети и импорт ZIP.
- Хранитель с кадрами рабочего стола либо собственной коллекцией и слайд-шоу.
- Просмотрщик: фильтры, масштаб, полный экран и слайд-шоу.
- Готовые кадры динамических тем с сервера; при недоступности нового кадра
  сохраняются текущие обои.

Клиент написан на Swift и AppKit; хранитель — на Objective-C. JavaScript и
отдельные утилиты определения мониторов не используются. Динамические темы
поступают готовыми JPEG: клиент не собирает слои изображения.

## Использование

В разделе **Обои** выберите экран, источник, коллекцию и условия, затем нажмите
**Применить**. Город появляется только для «Погоды в моём городе». Редкие
настройки находятся в «Дополнительно». Справа показаны текущие обои экрана.

**Хранитель** настраивается в отдельном разделе. В **Программе** доступны версия,
обновления, лицензии и кнопка «Исходники на GitHub».

## Сборка

Нужны macOS 12+ и Apple Command Line Tools либо Xcode со Swift 5.9+.
Из корня репозитория:

```sh
cd macos
./build-macos.sh
```

В `dist/` появятся универсальный DMG для Apple Silicon и Intel и `release.json`.
Зависимости включены в исходники. По умолчанию используется локальная подпись
ad-hoc. Сборка не запускает приложение и не меняет рабочий стол.

Параметры: `--app-only`, `--output DIRECTORY`, `--development`, `--signed`.
Для Developer ID и notarization нужны переменные `DEVELOPER_ID_APPLICATION` и
`NOTARY_KEYCHAIN_PROFILE` со своей конфигурацией подписи.

Для уже готового DMG метаданные можно создать отдельно:

```sh
./make-release.sh dist/ImperialSchoolViews-Mac-2.0.7.dmg
```

Файл `release.json` содержит `schema`, `app_id`, `platform`, `version`, `build`
и SHA-256 DMG. Имя DMG можно менять: сопоставление выполняется по хешу.

## Установка

Завершите старый клиент через значок в строке меню → «Выйти». Перетащите
приложение из DMG в Applications, извлеките образ и запустите из Applications.
Настройки и скачанные коллекции сохраняются в
`~/Library/Application Support/Imperial School Views`.

Модуль хранителя устанавливается кнопкой в разделе «Хранитель», затем выбирается
в системных настройках macOS.

## Проверки и лицензии

Отдельный сценарий разработчика `./test-core.sh` проверяет ядро и сценарии
управления. Проверки с моделями системных классов не заменяют запуск AppKit,
геолокации и хранителя на Mac.

Сторонние компоненты: ZIPFoundation 0.9.20 и Brotli 1.2.1 (MIT), системный zlib;
астрономические уравнения адаптированы из Astral 3.2 (Apache-2.0). Лицензии и
уведомления находятся в [`licences/`](licences/). Лицензия кода приложения пока
не определена; для обоев действуют отдельные условия.
