# Виды и обои · Android

Русский · [English](README.md) · [О проекте](../README.ru.md)

Версия **1.4.0**, Android 8.0+ (API 26), пакет `ru.oopssre.imperialschool.views`.

Клиент устанавливает обои из коллекций «Школы Империи».

Выберите коллекцию по превью, посмотрите изображение и нажмите «Применить…». Главный экран, блокировка или оба экрана выбираются при применении. Отмена сохраняет прежние обои и настройки. В меню «Установленные обои» можно обновить кадр, приостановить или отключить автосмену отдельно для каждого экрана.

Обычные, погодные и динамические коллекции остаются отдельными разделами. В каталоге и уведомлениях учитываются только коллекции с телефонным форматом. Если телефонный формат появился позже самой коллекции, это тоже новое поступление для телефона. Первое обновление реестра после установки 1.4.0 проходит без уведомлений обо всех старых коллекциях.

Поиск города и разовая геолокация доступны прямо в погодном разделе. Погода Столицы Империи и игровой мир остаются серверными источниками; Open-Meteo использует выбранный город. Настройки сети, скачивание коллекции, уведомления и сведения о приложении находятся в меню «Настройки».

Просмотрщик открывает сохранённые кадры без сети, поддерживает жесты, фильтры и слайд-шоу раз в две секунды. Дополнительные действия собраны в меню просмотрщика. Динамические сцены приходят готовыми JPEG с сервера. Поддержка видео и 4К для телефона не добавлялась.

Новая адаптивная иконка — телефон с геймпадом в цветах клиента TV. Для тематических значков Android есть отдельный монохромный слой.

## Сборка

Нужны JDK 17, Android SDK Platform 36 и Build Tools 36.0.0. Gradle wrapper фиксирует Gradle 8.13 и его контрольную сумму. При первом запуске зависимости скачиваются из сети.

Из этой папки:

```sh
export ANDROID_HOME=/абсолютный/путь/к/Android/sdk
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Отладочный APK появится в `app/build/outputs/apk/debug/`. Подписанная release-сборка:

```sh
./build-android.sh
```

Скрипт использует существующие настройки подписи либо создаёт личный ключ вне репозитория в `~/.config/imperial-school-views/`. Для другого существующего файла настроек:

```sh
IMPERIAL_SIGNING_PROPERTIES=/абсолютный/личный/путь/android-signing.properties ./build-android.sh
```

Пример файла (значения заполняются только локально, файл в Git не добавляется):

```properties
storeFile=android-release.jks
storePassword=YOUR_LOCAL_PASSWORD
keyAlias=YOUR_LOCAL_ALIAS
keyPassword=YOUR_LOCAL_PASSWORD
```

Относительный путь `storeFile` считается от папки файла настроек. Сборка с личным ключом не обновляет официально установленное приложение: для обновления требуется тот же ключ подписи.

## Публикация

В `dist/` появляются подписанный APK и `android-release.json` — файлы для размещения на сайте. Исходники распространяются через этот репозиторий. Личные копии ключа хранятся отдельно; сборщик больше не создаёт резервную копию ключа в дереве исходников.

В приложении есть ссылки на [репозиторий](https://github.com/GremlinEngineering/imperial-school-views) и [сообщения об ошибках](https://github.com/GremlinEngineering/imperial-school-views/issues).
