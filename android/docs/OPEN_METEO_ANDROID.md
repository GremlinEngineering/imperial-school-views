# Open-Meteo · Android 1.3.5

Обновление Android 1.2.0. Источники серверной погоды `real` и `game-world` сохраняют существующую логику API 1.7. Новый локальный источник `open-meteo` не передаётся серверу как новый серверный идентификатор.

## Общие правила с Mac

`assets/local-weather/astronomy.js`, `weather-policy.js`, `open-meteo.js` скопированы без изменений из ImperialSchoolViews_Mac_1.8.3.zip. Таблица WMO, календарные сезоны, четыре времени суток, солнечные события и восемь фаз Луны едины с Mac. Новый независимый алгоритм астрономии не вводится. Сезоны намеренно следуют существующей серверной таблице месяцев и не инвертируются для Южного полушария.

Для исполнения общих правил используется Rhino 1.7.15.1 в режиме интерпретатора, без генерации классов, WebView, сети из скриптов и Java-интерфейса. Скрипты встроены в APK; код с сервера не исполняется. Календарный адаптер использует java.time и часовой пояс выбранного города. Результат вычисления кешируется до следующей границы интервала или изменения прогноза/архива.

## Профили и данные

`weather_city` сохраняется как JSON-строка в каждом профиле. Отсутствующее поле в старом профиле означает отсутствие выбранного города; старые источники не меняются. Прогноз кешируется по координатам и часовому поясу; кадры и архив остаются общими для обоих экранов. Поиск требует явного выбора результата. С 1.3.3 отдельно доступно определение координат Android по кнопке с foreground-разрешением (достаточно приблизительного). Координаты сохраняются в том же weather_city с origin=device. Часовой пояс запрашивается по координатам через timezone=auto. Для нового места используется кнопка обновления; фоновое отслеживание не включено.

Прогноз обновляется раз в час и содержит 49 часов вперёд и один прошедший час в UTC. Сохранённый прогноз продолжает работать без сети до истечения срока. Расписание делится по часам, местным полуночам и солнечным событиям. При неизвестном коде, отсутствующем состоянии или истёкшем прогнозе последние обои сохраняются.

Локальный источник требует ZIP формата телефона выбранной коллекции. Он использует существующую проверку версии, SHA-256, размеров и декодирования JPEG. Выбор состояния делается по `state_id` и `moon_phase` из проверенного манифеста ZIP. Если готовый кадр повреждён, квитанция архива сбрасывается и ZIP загружается повторно. Для ZIP есть явный выбор: «Только Wi-Fi» или «Wi-Fi и мобильная сеть».

Подпись серверной реальной погоды — «Погода с сервера». Поле `location.name` больше не используется для её заголовка. Выбранный пользователем город Open-Meteo отображается.

## Проверка

Историческая проверка 1.3.2: 66 тестов JVM и Robolectric, включая 7 новых тестов Open-Meteo и отдельную проверку подписи сервера. Астрономия сопоставлена с Mac для 36 сочетаний города и даты, в том числе полярных условий, зон с дробным смещением и переходов DST. Проверены независимые города, совместимость старых профилей, почасовые интервалы, солнечные границы, лунные варианты, код 97, неизвестные/отсутствующие состояния и просроченный прогноз. Поиск городов проверен реальным запросом Open-Meteo.

Физический Android-телефон и Android-эмулятор в этой среде не запускались. Установка поверх предыдущей версии, внешний вид и фоновая работа на конкретной прошивке требуют проверки на устройстве.
