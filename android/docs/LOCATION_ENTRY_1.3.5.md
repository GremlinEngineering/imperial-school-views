# Видимый выбор города и геолокации · Android 1.3.5

Причина жалобы на отсутствие опции в 1.3.4: обе кнопки местоположения скрывались до выбора источника Open-Meteo. При выборе «Погоды дня» список источников содержал только серверную погоду и игровой мир. Это не давало видимого перехода к определению координат.

## Исправление

В разделе «Погодные обои» постоянно показан блок «Город или геолокация · Open-Meteo» с двумя кнопками:

- «Выбрать город вручную…»;
- «Определить по геолокации…» (после сохранения координат — «Обновить геолокацию…»).

В конкретной коллекции нажатие включает Open-Meteo и сразу открывает соответствующее действие. Предварительно выбирать провайдера через выпадающий список не нужно. Если активна «Погода дня», сначала открывается явный выбор конкретной погодной коллекции, затем поиск города или разрешение геолокации. Коллекция не подставляется без выбора пользователя. Отмена диалога коллекции оставляет «Погоду дня». Подпись объясняет переход к Open-Meteo. Сохранённый профиль меняется только после «Применить».

Разрешение геолокации запрашивается только по нажатию. Приблизительное разрешение, таймаут, отмена, сохранение координат и определение часового пояса сохранены из 1.3.3. Фоновое отслеживание не добавлялось. Погода дня, Brotli/gzip, архивы и выбор сети сохранены.

## Проверка

108 тестов JVM/Robolectric прошли без ошибок и пропусков. Включены 19 тестов интерфейса. Новые сценарии проверяют:

- видимость кнопок при real/game-world и нажатие геолокации с вызовом Android requestPermissions (код 21, coarse/fine);
- нажатие ручного выбора города из серверного источника с открытием поиска;
- переход из «Погоды дня»: диалог выбора коллекции, затем запрос геолокации.

Рендер проверен для обоих серверных источников, обоих daily-источников и Open-Meteo: светлая тема 360dp, тёмная 320dp, шрифт 150%. Надписи кнопок помещаются. Подписанная release-сборка, release lint, apksigner и zipalign прошли; сертификат прежний. Версия 1.3.5/build 10, Android 8+.

Физический телефон/эмулятор не запускался. Тесты интерфейса и системного запроса разрешения выполнены в Robolectric. Файлы действующего сайта автоматически не заменялись.
