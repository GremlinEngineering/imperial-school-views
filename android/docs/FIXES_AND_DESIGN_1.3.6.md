# Исправления и оформление · Android 1.3.6

## Исправленные состояния

| Проблема | Поведение 1.3.6 |
|---|---|
| Пауза сбрасывала несохранённый город и другие поля | Меняет только паузу; черновик сохраняется. Отдельные черновики главного экрана, блокировки и общего режима переживают переключение и пересоздание Activity. |
| Смешанное состояние паузы | Общая кнопка ставит оба управляемых экрана на паузу; «Продолжить» появляется, когда все они приостановлены. |
| Один повреждённый локальный набор блокировал каталог | Наборы проверяются по отдельности; исправные доступны, повреждённые перечислены в сообщении. |
| Ошибки смены сети ZIP скрывались сообщением об успехе | Возвращается результат с ошибками каждого задания; он показан в интерфейсе. Метаданные и путь проверяются до удаления старого запроса. |
| Длинная ошибка занимала весь экран | Статус ограничен двумя строками; нажатие открывает полное прокручиваемое сообщение. Вторичные действия перенесены в прокручиваемую область. |
| JPEG без задания показывал незапущенный ZIP | Блок ZIP скрыт, если он не используется и задания нет. |
| Назначение обновления было неясным | «Обновить установленные обои» обновляет сохранённые профили и явно не применяет черновик. |

При переключении сетевой политики незавершённый ZIP начинается заново. Готовые архивы используются повторно. Если новый запрос не удалось создать после удаления старого, задание получает видимую ошибку с возможностью повторить. Размер ZIP из каталога остаётся справочным; SHA-256 проверяется по исходным байтам.

## Фирменное оформление и Android

Палитра светлой/тёмной темы сверена с действующим CSS https://games.oopssre.ru/assets/style.css (ссылка из index.html). Снимок метаданных и SHA-256 CSS: BRAND_REFERENCE_1.3.6.json. Oswald используется в заголовках, Literata в вводном тексте, PT Mono в технических подписях. Управление использует системный sans-serif Android.

Настройки расположены перед большим превью. Сводка профилей сворачивается. Элементы управления имеют обратную связь на нажатие и фокус, списки — стрелки. Увеличены цели нажатия до 48 dp, добавлены подписи доступности. При крупном шрифте вторичные кнопки стоят вертикально.

Проверены цели нажатия, восемь пар цветов текста/фона с контрастом не ниже 4.5:1, светлая/тёмная темы, шрифт до 200% и длинная ошибка. Используются фирменная тема и Android Views. Полная миграция на библиотеку Material 3 не выполнялась; соответствие всем рекомендациям Google не заявляется.

Ориентиры Google:

- https://developer.android.com/guide/topics/ui/accessibility/apps
- https://developer.android.com/about/versions/14/behavior-changes-all#non-linear-font-scaling

## Проверка и пределы

122 теста прошли без ошибок и пропусков, в том числе 31 UI-тест. Матрица содержит 72 сочетания экранов и 22 состояния ZIP; это не доказательство перебора всех возможных состояний Android. Проверены черновики при паузе, переключении и пересоздании Activity, смешанная пауза, сохранение исправного локального набора, скрытие ZIP для JPEG, полный текст ошибки, сетевые флаги реального ShadowDownloadManager и сохранение старого запроса при невалидных метаданных. Подпись APK прежняя; release lint и zipalign прошли.

Физическое устройство и системный эмулятор не запускались. Работа GPS, обоев и фоновых задач на конкретных прошивках требует проверки установленного APK. Это граница выполненной проверки, а не недостаток спецификации. Серверная спецификация 1.7 и прежние функции, включая Brotli JSON, ручной город, одноразовую геолокацию и отдельную «Погоду дня», сохранены и покрыты существующими тестами.
