# Историческая сверка API 1.7

Таблица ниже относится к Mac 1.6.0 и Android 1.2.0. Актуальная сверка: [API_PARITY_1.3.3.md](API_PARITY_1.3.3.md).


| Функция | Mac 1.6.0 | Android 1.2.0 |
| --- | --- | --- |
| Сетевой каталог | Только manifest-v3.json | Только manifest-v3.json |
| Погодный кадр | Интервал действующего совместимого прогноза | Тот же выбор, телефонные форматы |
| Таймер | Локальная граница valid_until, отдельные JSON и ZIP | AlarmManager, отдельные WorkManager и DownloadManager |
| Пакет | Независимый package_version для каждого формата | Независимый package_version телефонного формата |
| Кеш JPEG | SHA-256, проверка байтов/разрешения | То же |
| Постоянный URL изменился | Перечитать текущий JSON, прогноз и каталог | То же, ограниченные повторы |
| Очистка | Текущие экраны, прогнозы и последний пакет защищены | Оба профиля, прогнозы и последний пакет защищены |
| Обычный пакет с сайта | Кнопка загрузки → Сохранённые → Применить | Загрузка → Использовать скачанный → Применить |
| Обои дня | Ежечасная проверка нового выбора сайта | Ежечасная проверка, отдельно от смены дня |
| Главный / блокировка | Рабочие столы Mac | Два независимых профиля, общий режим и «Не менять экран» |

После потери связи используется проверенный прогноз до valid_until. После истечения сохраняются установленные обои с отметкой об отсутствии подтверждённой текущей погоды. Календарь, сезон, погоду и год мира вычисляет сервер. Клиенты не вызывают Luna и не пересчитывают астрономию.

Старые погодные JSON не используются после перехода. Обычные импортированные наборы и настройки сохраняются. Сохранение или загрузка пакета отдельно от системного применения.

Проверки и ограничения нативного исполнения описаны в VALIDATION.md. [Аркадный зал](https://games.oopssre.ru/index.html) · [Лаборатория](https://games.oopssre.ru/lab/).
