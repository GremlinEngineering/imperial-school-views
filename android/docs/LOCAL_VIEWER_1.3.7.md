# Локальный просмотрщик · Android 1.3.7

Основа — принятая пользователем 1.3.6. Версия 1.3.7 добавляет отдельную закрытую Activity и кнопку под выбранной коллекцией; передаётся текущий черновик без его применения. Профили и расписание не меняются.

## Откуда берутся кадры и условия

| Режим | Источник описания | Локальный файл |
|---|---|---|
| Погодная коллекция, ZIP | Успешно установленный манифест weather-packages, варианты нужной коллекции и телефонного формата | weather-images/<sha256>.jpg |
| Погодная коллекция, JPEG | Сохранённые интервалы прогнозов этой коллекции/формата, включая города Open-Meteo | weather-images/<sha256>.jpg |
| Погода дня | Сохранённый current.json выбранного серверного источника, files.phone | weather-images/<sha256>.jpg |
| Обычные обои | Сохранённый каталог или манифест импортированного пакета | online/<sha256>.jpg или файл импортированной коллекции |

Просмотрщик не выполняет HTTP-запросы, не создаёт DownloadManager-задания и не обновляет прогноз. Уже действующая автосмена обоев продолжает работать независимо. Для JPEG доступны кадры с сохранившимся описанием. Изображения без метаданных темы/условий не приписываются теме по догадке. Bundled-превью не выдаются за скачанные обои.

Отдельные поля season/time_of_day/weather имеют приоритет. Если манифест ZIP содержит только state_id, применяется установленный в API 1.7 формат: распознаются два фиксированных префикса сезона и времени суток, весь оставшийся суффикс является погодой. Имена JPEG не разбираются. Неизвестные значения показываются как есть. moon_phase=none означает отсутствие лунного слоя, а не новолуние.

Кадры объединяются по SHA-256, все разные правила сохраняются. Все выбранные фильтры должны подходить одному и тому же правилу. Сведения об установленном кадре сопоставляют сохранённый хеш и текущий wallpaper ID Android, чтобы не отмечать кадр после внешней смены обоев.

## Управление и состояния

- Листание кнопками или горизонтальным свайпом; края списка не переходят по кругу.
- Увеличение двойным касанием или двумя пальцами до 6×, перетаскивание увеличенного изображения. Перетаскивание при увеличении не меняет кадр.
- Полный экран по кнопке или касанию изображения; касание/Back возвращает управление. На Android 13+ системный back callback включён только в полном экране; после возврата управления снимается, чтобы обычный возврат Activity обрабатывала система. Старый onBackPressed сохранён только для Android 8–12; предупреждение GestureBackNavigation подавлено только на этом legacy-методе, современный путь не использует его. Ориентир: https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture.
- Фильтры открываются в прокручиваемом диалоге; можно отменить, применить и сбросить. Пустой результат не блокирует сброс.
- Полные условия открываются в отдельном прокручиваемом диалоге. Краткая подпись ограничена тремя строками.
- Позиция и фильтры сохраняются при пересоздании Activity. Настройки основного окна остаются черновиком.
- Пустой кеш сообщает, где скачать кадры. Повреждённый или удалённый во время просмотра файл показывает ошибку; переход к другому кадру и выход доступны.

Индекс читается в фоне. Перед открытием файла проверяются SHA-256, число байтов и размеры; декодирование уменьшает картинку под экран с пределом 2048 px по каждой стороне. В интерфейсе удерживается одна уменьшенная картинка. Устаревший результат декодирования не заменяет новый кадр; ошибки декодирования и нехватки памяти обрабатываются.

## Проверка

Новые тесты проверяют группировку условий, отсутствие ложных сочетаний фильтров, отброс отсутствующих файлов и чужой коллекции, сохранённые JPEG без ZIP, обычную коллекцию, «Погоду дня» без прогноза, отсутствие ложной отметки установленного кадра, повреждённый файл, пустое состояние, листание, увеличение, полный экран/Back, подробности, восстановление позиции, фильтры без совпадений и сброс, кнопку под темой и сохранность черновика. Интерфейс просмотрен в Robolectric при шрифте 200%.

Физическое устройство/системный эмулятор не запускались. Подтверждение работы жестов и системных панелей конкретной прошивки требует установки APK. Исторические проверки 1.3.6 сохранены; результаты текущей сборки указаны в VALIDATION.md и XML test-results.
