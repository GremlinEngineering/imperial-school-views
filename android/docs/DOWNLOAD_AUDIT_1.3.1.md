# Android 1.3.1 · проверка загрузок и интерфейса

Проверка действующего сайта 30.10.2026 и исходников Android 1.3.1.

## Что скачивается

| Режим | Источник | Файлы |
| --- | --- | --- |
| Обои дня / обычная коллекция онлайн | `manifest-v3.json` → выбранный item | Вертикальный JPEG текущего вида. ZIP автоматически не нужен. |
| Скачать обычную коллекцию | `downloads[id=collection-<id>]` | ZIP выбранной коллекции. Существующие обычные ZIP содержат несколько форматов; после импорта клиент оставляет телефонные JPEG. |
| Серверная погода / Игровой мир, JPEG | выбранная коллекция → source → `current_url`, `forecasts.phone` | Текущий JSON, прогноз телефона, текущий и ближайший следующий JPEG. |
| Серверная погода / Игровой мир, ZIP | те же JSON, затем `downloads[collection, rendition=phone]` | Текущий JPEG для быстрого показа и общий ZIP телефона. Проверенные локальные кадры повторно не скачиваются. |
| Open-Meteo | поиск города и прогноз его координат; каталог сайта для коллекции | Прогноз выбранного города и общий ZIP `phone` выбранной коллекции. Серверные `current.json` и прогнозы реального/игрового источника для Open-Meteo не запрашиваются. |
| Сохранённая коллекция / импорт | файл пользователя | Локальный ZIP, затем локальные JPEG. Источник сам по себе не запрашивает погоду или архив с сервера. |

База сайта: `https://games.oopssre.ru/assets/arcade/views/`. Погодные ZIP выбираются по паре «коллекция + формат», а не по городу, источнику или экрану. Один ZIP используется для главного экрана и блокировки, а также разных городов. В Android выбирается вертикальный формат `phone`; настольные погодные ZIP не загружаются.

URL погодного ZIP берётся из каталога. Его версия сопоставляется с `package_version` прогноза для серверного источника. Для Open-Meteo используется текущая версия из каталога. Готовность локального ZIP хранится по его SHA-256. Метаданные перепроверяются раз в сутки; изменение версии/хеша требует нового пакета, повторное применение того же пакета — нет.

## Проверка файлов сайта

Полностью скачаны и проверены оба погодных ZIP:

| Коллекция | Формат | Размер, байт | Кадров | Результат |
| --- | --- | ---: | ---: | --- |
| Chip ’n Dale | phone | 561088429 | 264 | SHA-256 ZIP, версия, формат, SHA-256 и разрешения всех кадров совпали |
| Metal Slug X | phone | 670566642 | 264 | SHA-256 ZIP, версия, формат, SHA-256 и разрешения всех кадров совпали |

SHA-256 всех четырёх обычных ZIP также совпал с каталогом. Проверены их манифесты, имена файлов и SHA-256 изображений. «Под крылом» — 12 телефонных кадров, «Мир с глубиной» — 4, месячная коллекция — 12, сезонная — 4. Состав архивов совместим с импортом Android.

Проверены `current.json` и прогнозы телефона обоих серверных источников для обеих погодных коллекций. Версии прогнозов совпали с каталогом ZIP. На момент проверки размеры ZIP в HTTP и каталоге также совпадали; ошибку размера по текущим файлам сайта воспроизвести не удалось.

## Исправления

- Загрузка обычных и погодных ZIP разрешена по Wi-Fi и мобильной сети. Старые незавершённые запросы с прежними сетевыми флагами заменяются запросами с новой политикой.
- Размер ZIP из каталога больше не является условием принятия файла. Целостность определяется по SHA-256 всего файла, затем проверяются ZIP, манифест и изображения. Размер нужен для прогресса; после начала загрузки приоритет имеет размер от DownloadManager.
- Добавлены явная отмена скачивания и повтор. Отмена сохраняется и не вызывает немедленный автоматический перезапуск. Обработка уже загруженного ZIP завершается отдельно.
- Исправлена валидация сохранения Open-Meteo: реальное хранилище профилей теперь принимает этот источник и проверяет наличие города/ZIP.
- Исправлен выбор профиля ZIP при разных погодных источниках экранов. ZIP начинает подготавливаться независимо от готовности текущего погодного кадра.
- Причины отсутствия превью видны пользователю. Ошибки сети, таймаута, доступа, данных и нехватки памяти имеют понятные сообщения. Ошибка обновления каталога не скрывается при использовании сохранённой копии.
- Во время применения, импорта и загрузки каталога управляющие элементы блокируются. Обновление превью не сбрасывает токен загрузки каталога. Ошибки не вытесняются мгновенно старым фоновым статусом.
- Проверены обычный, серверный, игровой и городской интерфейсы, светлая и тёмная тема, экран 320 dp и шрифт 150%. Высота кнопок и списков адаптируется к тексту; ссылки при крупном шрифте расположены в два ряда.

## Границы проверки

60 тестов JVM/Robolectric. В том числе реальное сохранение двух профилей, нажатие «Применить» для Open-Meteo, сетевые флаги DownloadManager, отказ при отсутствии города, видимость ошибок, блокировка элементов при операции, повтор после отмены и принятие исправного ZIP с неверным `bytes` в метаданных.

Robolectric исполняет интерфейс Android и его отрисовку в тестовой среде. Физический телефон и Android-эмулятор не запускались; работа фоновых служб на конкретной прошивке не подтверждена. Подпись APK и zipalign проверены отдельно.
