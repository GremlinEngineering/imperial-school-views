# Виды и обои · Школа Империи

Русский · [English](README.md)

Клиенты обоев **«Школы Империи»** для Android, macOS и Windows.

Приложения связывают коллекции на [games.oopssre.ru](https://games.oopssre.ru/) с обоями устройства. Кадры выбираются по сезону, времени суток и погоде. Динамические сцены собирает сервер с учётом погоды и игровых событий, а клиент получает готовое изображение.

## Что делает проект

- Работает с обычными, погодными и динамическими коллекциями сайта.
- Поддерживает серверную погоду, погоду игрового мира и выбранное место Open-Meteo в тех клиентах, где соответствующая функция реализована.
- Позволяет просматривать скачанные изображения без сети и сохраняет последние обои при ошибке обновления.
- В Android предоставляет просмотрщик и слайд-шоу.
- Использует настройки экранов своей платформы; в Android есть отдельные профили главного экрана и блокировки.

Динамические обои поступают готовыми JPEG с сервера. Текущая Android-версия не собирает слои и не рассчитывает будущие сцены на устройстве.

## Состояние репозитория

Сейчас здесь находится документация проекта. Перенос исходников Android 1.3.8 ожидает подготовки; исходники macOS и Windows будут добавлены отдельно после проверки актуальных версий.

Возможности платформ и инструкции сборки будут описаны вместе с их исходниками. Перечень выше не означает одинаковую реализацию всех функций на каждой платформе.

## Подпись и лицензии

Ключ издателя, пароли и личные резервные копии подписи хранятся вне репозитория. Для самостоятельной сборки используется собственная конфигурация подписи.

Лицензия кода будет указана при переносе исходников. У сторонних компонентов сохраняются их лицензии; для изображений обоев действуют отдельные условия.
