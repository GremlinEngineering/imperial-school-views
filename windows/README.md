# Виды и обои · Школа Империи · Windows 1.2.0

Русский · [English](README.en.md)

Исходники Windows 10/11 x64. Сборка создаёт полный установщик в `dist/` с включённой .NET.
Готовые установщики распространяются на [сайте проекта](https://games.oopssre.ru/).
Установка поверх 1.0.1/1.1.0 сохраняет настройки, скачанные коллекции и обои.

Подпись реальной погоды сервера — **«Погода Столицы Империи»**. Город показывается
только для Open-Meteo. Часовой пояс для геолокации уточняется по координатам,
для поиска города приходит вместе с выбранным результатом.

## Как пользоваться

Выберите вкладку обычных или погодных обоев, источник, коллекцию и экран.
Нажмите **Применить**. Окно остаётся открытым. Его закрытие оставляет приложение
в трее. Завершение — через меню значка.

Для разных обоев на экранах включите **Отдельные настройки каждого экрана**.
Выберите экран, настройте его и примените; затем настройте следующий.
Изменения сохраняются кнопкой «Применить». У нового экрана автосмена по умолчанию
выключена. Профили привязаны к системному идентификатору монитора.

Для своего города выберите **Погода в моём городе · Open-Meteo** и кнопку выбора
города. Доступны поиск и **Моё местоположение**. Windows должна разрешить
геолокацию; при отказе остаётся поиск по названию. После применения скачивается
полный погодный ZIP нужного формата. До его готовности остаются прежние обои.
Предпросмотр не запускает скачивание полного ZIP.

Для серверной погоды сначала устанавливается текущий проверенный JPEG,
затем готовится ZIP, если выбран такой способ доставки. Большой архив
скачивается потоком, проверяется и распаковывается. Приложение и хранитель
используют общую блокировку пакета, чтобы не скачивать один ZIP одновременно. После сбоя одна и та же
ошибочная версия не скачивается непрерывно; явное повторение — «Обновить сейчас».

**Просмотр и слайд-шоу** открывает сохранённые кадры. Фильтры объединяются;
одинаковые файлы не повторяются в списке после фильтрации. Масштаб меняется
колесом мыши, доступны вписывание и 100%; F11 — полный экран, стрелки — кадры,
Esc — возврат или закрытие. Просмотрщик сам не меняет системные обои.

## Хранитель Windows

Кнопка **Выбрать хранитель Windows** регистрирует установленный `.scr` для
текущего пользователя и открывает настройки экрана блокировки Windows.
Время запуска и необходимость входа после хранителя задаются средствами Windows.

По умолчанию хранитель показывает текущие обои каждого экрана и подхватывает
их обновление. Для собственной коллекции включите соответствующую настройку,
выберите уже скачанную коллекцию и интервал слайд-шоу (10–3600 секунд).

Для собственного расписания или погоды выберите нужные обои в верхней части
окна и нажмите **Взять выбранные настройки для хранителя**. Отдельный профиль
запоминается; после этого можно выбрать другие настройки рабочего стола.
Нажмите «Применить» для сохранения. Хранитель сам получает нужные кадры;
при ошибке сохраняет уже показанный кадр. Для старта используется текущий фон
экрана, пока собственный кадр готовится.

Кнопка предпросмотра запускает полноэкранный хранитель с сохранёнными настройками.
Движение мыши или клавиша завершают просмотр. Поддерживается системный `/p` preview.

## Данные и надёжность

Сохраняются прежний app_id `ru.oopssre.imperial-school.views.windows`,
папка `%LOCALAPPDATA%\Imperial School\Views`, автозапуск и ярлыки.
Настройки мигрируют без ручных действий. Для возврата к одному профилю достаточно
выключить отдельные настройки экранов и применить выбор.

Смена кадров идёт по границам серверных интервалов, местным суткам или выбранному
расписанию. Open-Meteo обновляется раз в час, а рассвет, восход, закат, сумерки,
полночь и фазы луны рассчитываются теми же уравнениями, что в Mac 2.0.7.
Динамические темы приходят готовыми изображениями; клиент не собирает слои.

JSON поддерживает HTTP gzip/deflate/Brotli и опубликованные `.json.br`.
Проверяются размер и SHA-256 изображений, размеры JPEG, версия и состав ZIP,
идентичность мира и `location_revision`, срок и формат кадра. Истёкший прогноз
не заменяется случайным изображением. При пропаже сети последние обои остаются.
Смена обоев вне приложения приостанавливает автоматическую смену.

Остаются последние погодные пакеты каждого оформления/формата и действующие
прогнозы. Для прочих кешированных JPEG — около 128 МБ / 64 файлов; текущие обои
защищены от очистки. Метаданные истории ограничены 96 записями. Импортированные
обычные коллекции автоматически не удаляются. Журнал — `app.log` в папке данных.

## Для сайта

Сборщик создаёт в `dist/` актуальный Setup.exe и плоский
`windows-release.json` с шестью полями: `schema`, `app_id`, `platform`, `version`,
`build`, `sha256`. Выпуск связывается по SHA-256; EXE можно переименовать.

Оба файла положить в существующую папку установщиков внутри каталога контента:
`editorial/wallpapers/views/installers/`, затем выполнить обычную сборку сайта.
Серверные скрипты этим пакетом не изменяются.

## Сборка и проверки

Версия **1.2.0**, build **4**. .NET SDK **10.0.403**, NSIS 3.x.
На Windows запустить `build-windows.cmd` или `build-windows.ps1`.
Сборщик компилирует клиент, добавляет `.scr`, упаковывает Setup.exe и создаёт
`windows-release.json`. Проверки отдельно:

```text
dotnet run --project Checks/Checks.csproj -c Release
```

Проверка опубликованного сервера без загрузки большого ZIP:

```text
dotnet run --project Checks/Checks.csproj -c Release -- --live
```

Границы фактически выполненной проверки — в `VALIDATION.md`.
Исходники: https://github.com/GremlinEngineering/imperial-school-views
Лицензии компонентов — `Licenses/`, шрифтов — `Desktop/Assets/`.
Код приложения не получил новую лицензию; права на иллюстрации определяются отдельно.
