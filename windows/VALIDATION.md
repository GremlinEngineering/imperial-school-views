# Проверка Windows 1.2.0 · build 4

Основа: Windows 1.1.0, функциональная сверка с Mac 2.0.7.

## Выполнено 1 ноября 2026

- Реальная компиляция всего приложения и self-contained публикация win-x64,
  .NET SDK 10.0.403, закреплённые зависимости. Компиляция без ошибок и предупреждений.
- 59 переносимых проверок: прежние 45 и 14 новых. Новые покрывают астрономию
  на эталонных данных Mac/сервера для разных городов, сезонов, часовых поясов и
  полярных дней; точные границы восхода/заката; сохранение независимых профилей
  двух экранов и миграцию прежнего выбора; неизвестные экраны; сериализацию города;
  WMO 97, точный выбор состояния/фазы луны, отказ неизвестного кода и истёкшей
  погоды; подпись Столицы Империи; JSON погоды дня и динамики; Brotli и лимит
  распаковки; почасовой кеш Open-Meteo и смену координат; общую блокировку погодного ZIP
  между независимыми экземплярами хранилища приложения и хранителя.
- 3 проверки опубликованного сервера: принят актуальный manifest-v3.json,
  получены и проверены реальные JPEG серверной погоды и игрового мира,
  их длина, SHA-256 и JPEG-размеры. Большой погодный ZIP повторно не скачивался.
- Установщик NSIS собран. 7-Zip проверил целостность и распаковал EXE.
  Все 282 файла приложения из установщика побайтно совпадают с опубликованной
  полезной нагрузкой, включая EXE, DLL, `.scr`, ресурсы и лицензии.
- EXE и `.scr` — настоящие GUI PE32+ x86-64. В `.scr` используется тот же apphost
  и общий набор DLL/.NET, отдельная установка среды не нужна.
- `windows-release.json` содержит шесть стандартных верхнеуровневых полей;
  версия/build и SHA-256 совпадают с фактическим установщиком. Пакет сайта
  содержит только EXE и этот JSON. Контрольные суммы исходников
  перечислены в FILES_SHA256.txt.

## Границы проверки

Проверки выполнялись на Linux. Нативный интерфейс WinForms, системная геолокация,
COM SetWallpaper/GetWallpaper, запуск `.scr` и его предпросмотр в панели Windows,
установка и удаление на настоящей Windows в этой среде не запускались.
Проверка упаковки и компиляция этого не заменяют.

Сохранено исправленное перечисление мониторов без GetMonitorRECT из Windows 1.0.1.
Новая 1.2.0 требует проверки установки и запуска на Windows.
