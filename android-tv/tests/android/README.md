# Проверка интерфейса 0.7.0

`TvUiTest` предназначен для отдельного тестового устройства или чистого эмулятора: он заменяет настройки и кеш тестовыми данными. На основном телевизоре его запускать не требуется.

Соберите приложение (`build.py`) и тест (`tests/android/build_test.py`) с одним ключом. Установите оба APK, затем выполните:

```sh
adb shell am instrument -w ru.oopssre.imperialschool.viewstv.test/ru.oopssre.imperialschool.viewstv.TvUiTest > instrumentation.txt
adb pull /sdcard/Android/data/ru.oopssre.imperialschool.viewstv/files/qa-070 proofs
```

Проверяются короткий/долгий OK, три основных действия, отсутствие служебных функций в основном меню, управление музыкой и громкостью стрелками, восстановление фокуса, три группы коллекций, превью без применения, выбор с возвратом к сцене, параметры коллекции, QR-ссылки, сведения о музыке, очистка с ожиданием очередей и сохранением настроек, конечная цепочка Back.

Превью и фон в этих проверках используют явно подготовленные снимки изображений. Это проверка Android UI и навигации, а не живой серверной публикации и не аппаратного HEVC. `TvVideoTest`/`Tv4kTest` остаются отдельными проверками; 4К-аппаратуру подтверждают на подходящем физическом устройстве.
