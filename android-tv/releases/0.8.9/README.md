# Android TV 0.8.9, сборка 23

«Виды Школы Империи» в светлой и вечерней палитрах блога. Тема выбирается в разделе «Настройки → Оформление». Боковое меню, предпросмотр коллекций, настройки и экран музыки используют прежние действия и управление пультом.

Громкость применяется к звуку самого приложения. Настройки звука приложения и заставки сохраняются отдельно. При выключенном звуке выбор радиостанции сохраняет станцию для текущего режима. Воспроизведение запускается при включении звука.

## Воспроизводимая сборка

Входной файл — официальный `ImperialSchoolViewsTV_0.8.8.apk`. Нужны JDK 17, Python 3, Apktool 2.12.1, Android SDK Platform 35 и Build Tools 35.0.0.

```sh
./rebuild_unsigned.sh /path/to/ImperialSchoolViewsTV_0.8.8.apk /path/to/apktool_2.12.1.jar \
  "$ANDROID_SDK_ROOT" /tmp/ImperialSchoolViewsTV_0.8.9_unsigned.apk
```

Нативные библиотеки, ресурсы и данные коллекций берутся из входного APK. Java-файл `BlogUi.java` содержит интерфейс новой версии, а `patch_release.py` подключает его к действующим экрану, каталогу и аудиодвижку 0.8.8. Классы из `compile-only/` используются только для компиляции. Для установки поверх 0.8.8 подпишите APK тем же ключом издателя.
