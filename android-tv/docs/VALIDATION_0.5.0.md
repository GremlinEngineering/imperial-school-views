# 0.5.0 · build 10

Выполнено:

- 73 прежние автономные проверки протокола, профилей, кеша, пульта и обновлений.
- 34 новые проверки реальных VideoLoader/HttpTransport/CacheStore с локальным HTTPS-обработчиком: неизвестная будущая тема, профиль и геометрия, необязательное видео, соответствие JPEG, ограничение размера, два часа актуальности, случайные 10–20 минут, удалённый MP4 → свежие JSON → новый URL, ETag/304, прежний SHA без скачивания, свежие времена при том же MP4, повреждённый хеш, обрыв и удаление .part, повтор с нуля, защита активного и подготовленного файла в общем кеше.
- Полный APK компилируется Android SDK 36 и подписывается прежним сертификатом.
- Android-инструментальные тесты компилируются. Новый тест использует реальные отдельные HEVC A/B через production API подготовленного кеша; они находятся только в исходниках теста.
- Проверяется стандартный комплект APK + плоский android-tv-release.json, без вложенного assets/.

Границы:

- Пользователь подтвердил A↔B без мигания и отдельную музыку у 0.4.4 на Яндекс ТВ.
- Новая 0.5.0 здесь на физическом ТВ или эмуляторе не запускалась.
- Реальная серверная выдача MP4 не проверялась: сборщик ещё реализуется отдельно. Сетевые сценарии проверены по согласованному контракту, без изменения сервера.
- Плавность при смене конфигурации HEVC/FPS/входного буфера не подтверждена устройством. Для одинаковой конфигурации используется проверенный однокодековый путь на том же Surface; для отличающейся нужна переинициализация.

Обычный JPEG-режим и независимая музыка сохранены. Определение серверного видео идёт по dynamic + desktop_3840x2160 + video, а не по ID темы. Расширение видео не требует нового APK для каждой будущей темы.
