# 0.4.1 · build 6

- 73 проверки на JDK 21: Авто, 4К при сообщённых 1080p, Full HD при сообщённых 4К, строгий ручной профиль и ожидание его публикации, прежние протоколы/кеш/обновления/удержание OK.
- Полный APK собран с официальным Android SDK Platform 36 / Build Tools 36.0.0, проверены app ID, versionName=0.4.1, versionCode=6 и подпись прежним ключом.
- Все встроенные assets побайтно совпадают с 0.4.0; музыка, шрифты и рисунки сохранены.
- Исправлен путь переключения: один и тот же SHA не отменяет повторное декодирование при смене целевого размера.
- При нехватке памяти ручной режим сообщает ошибку и сохраняет показанный кадр; молчаливое понижение разрешения допускается только в Авто.

На эмуляторе и физическом ТВ 0.4.1 не запускалась. Размер Surface/Bitmap сам по себе не доказывает физический вывод 4К прошивкой. Для проверки на телевизоре: удерживать OK → Разрешение → 4К; затем О приложении → Состояние и кеш. Должны различаться и честно показываться: определение Android, запрошенный/показанный профиль, файл, Bitmap, запрошенный/фактический буфер. У 4К-кадра при ручном 4К ожидаются файл, Bitmap и буфер 3840×2160. Отдельно проверить переключение на Full HD и обратно, закрытие/повторный запуск и запуск заставки с сохранённой настройкой.
