# Проверка интерфейса TV 0.6.0 — 06.11.2026

Проверка логики выполнена по исходникам. Новый UI APK скомпилирован; запуск интерфейса на Android TV здесь не выполнялся. Автономные проверки не являются проверкой аппаратного вывода на телевизоре.

## Обнаруженные причины и исправления

| Проблема 0.5.0 | Причина | Изменение 0.6.0 |
|---|---|---|
| Пропадают погодные и обычные обои | `themeList` пропускает все группы кроме dynamic при video_output | Список всегда включает все три группы; эффективный видеорежим зависит от вида выбранной коллекции |
| После выбора обычных обоев видео мешает показу | Глобальный флаг одновременно использовался как предпочтение, фильтр каталога и выбор контроллера | Предпочтение сохранено отдельно; обычные и погодные обои используют контроллер картинок |
| Единственная повреждённая запись скрывает каталог | JSONException отдельной коллекции выходит наружу, репозиторий возвращает только тему по умолчанию | Ошибки отдельных записей изолированы |
| В меню музыки технические описания и длинные суффиксы | `pack.description`, FM/SNES/каналы/цитаты выводятся рядом с повседневными действиями | Оставлены действия, название, состояние; происхождение и атрибуция отдельно в About |
| Главные настройки длинные, почти все кнопки на одной странице | Вывод/разрешение/масштаб/обновление/состояние смешаны | Экран и обновление приложения вынесены в собственные страницы |
| «Назад» из громкости/разрешения возвращает не туда | Неполная карта родителей | Для громкости родитель Музыка, для разрешения/масштаба/вывода — Экран |
| После возврата фокус перескакивает к началу | `focusFirst` всегда выбирает первый элемент | Запоминается устойчивый ключ элемента и прокрутка страницы |
| Нельзя понять и очистить весь кеш | Объём был только в длинной диагностике и не включал APK | В настройках виден объём; отдельная страница показывает разбивку и безопасную очистку |
| На экране ожидания появляются внутренние ошибки | В placeholder попадали status и строка декодера | Краткое понятное состояние; полная ошибка и размеры — в диагностике |

Сохранены: запуск сразу в обои, удержание OK ровно от одной секунды, поглощение отпускания после открытия, короткий OK без действия во время показа, общий UI Activity/DreamService, независимые переключатели звука и отдельная музыка, сведения о версии и авторе. Иконка, шрифты и цвета прежние.

## Основания для навигации

Использованы рекомендации Android TV: все действия достижимы с D-pad, один явно выделенный фокус, понятная последовательность Back, минимум уровней до основного контента, читаемые крупные элементы и безопасные отступы. Существующая палитра проекта и контрастный янтарный фокус сохранены. Отступы панели увеличены; обычные страницы без моноширинных технических блоков.

Первичные источники:
- https://developer.android.com/design/ui/tv/guides/foundations/navigation-on-tv
- https://developer.android.com/design/ui/tv/guides/styles/focus-system
- https://developer.android.com/training/tv/get-started/navigation

## Очистка кеша

Осознанное действие кнопкой без дополнительного окна подтверждения. Загрузки отменяются; очереди загрузки изображений, видео и декодера дожидаются освобождения ресурсов. Затем очищается только `Context.getCacheDir()`, без каталога SharedPreferences и встроенных assets. Видеопины дополнительно защищают открытые файлы. Кеш-каталоги воссоздаются, текущий выбранный источник запрашивается заново. Счётчик после очистки может начать расти сразу из-за новой загрузки.

Проверены на хосте: целостность PNG/JPEG, старый кеш без поля format, разделение PNG master и JPEG alternative, source_image_sha256 ролика, независимость типов коллекций от видеофлага, ошибочная отдельная запись, удаление файлов и сохранение настроек, блокировка очистки активным видеопином, восстановление каталогов.

Подготовлен актуальный `TvUiTest` для реального Android TV: пульт, фокус после Back, все три категории в видеорежиме, переключение к погодным и обычным картинкам и обратно, нативный PNG BitmapFactory, очистка и сохранение параметров. Его APK собран, но тест не запускался; старые снимки не используются как доказательство нового интерфейса.
