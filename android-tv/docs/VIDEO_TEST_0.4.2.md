
## Встроенная проверка 4К-видеовывода (0.4.2)

Удержать OK одну секунду → «Вывод через видео» → включить. По умолчанию опция выключена. Включение сохранено для приложения и заставки. Играет встроенный ролик Орбиты 3840×2160, HEVC Main 8-bit, 24 кадра/с, 4 секунды, 1032438 байт, без аудиодорожки. Видео повторяется до выключения опции. Серверный текущий кадр в этом тесте не загружается и не подменяется встроенным якобы актуальным кадром. Выключение возвращает выбранную коллекцию и её обновления.

Вывод — MediaExtractor → выбранный аппаратный MediaCodec → отдельный полноэкранный SurfaceView. Software decoder не используется: при отсутствии подходящего аппаратного HEVC-декодера отображается ошибка. Android 29+ сообщает аппаратный признак; на 26–28 исключаются известные программные декодеры и показывается имя вендорного кодека без утверждения о подтверждённом аппаратном флаге. Низкое разрешение интерфейса не навязывается как display mode видеопути.

По умолчанию видео заполняет весь экран с сохранением пропорций. Режим размещения видео хранится отдельно от картинки. Музыка Орбиты идёт существующим независимым плеером, с прежними флагами приложения/заставки и громкостью. Цикл видео не меняет трек, позицию музыки или audio focus. При остановке приложения/заставки видеодекодер освобождается.

В «О приложении → Состояние и кеш» есть имя/тип декодера, видимый размер декодированного видео, Surface и число завершённых циклов. Наличие HW Overlay не объявляется подтверждённым по одним этим данным. Встроенный ролик и приложение не требуют серверной выдачи MP4; изменения видео-публикации на сайте — следующий отдельный этап.

Проверить на физическом ТВ: полноэкранность при закрытом меню, мелкие детали, стык каждые 4 секунды, музыка дольше двух видеоповторов, включение/выключение обоих звуковых флагов, долгий OK, выход и повторный запуск, заставка. TvVideoTest в tests/android — инструментальный тест для устройства с аппаратным HEVC 4К; в текущей среде не запускался.
