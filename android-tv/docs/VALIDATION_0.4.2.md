# 0.4.2 · build 7

- Сборка полного APK с Android SDK 36.
- 73 прежние проверки ядра прошли.
- Android-инструментальные тесты, включая новый TvVideoTest, компилируются. Здесь они не запускались: в среде нет физического аппаратного HEVC-декодера ТВ.
- Видеопример собран нативным space-layers 1.0.82 из существующей темы Orbital Port 1.6: истребитель, новый борт, гостевой корабль, грузовой караван, оранжерея и освещение. Данные сборки и ролика: VIDEO_SOURCE_0.4.2.json.
- HEVC-ролик проверен ffprobe и двумя последовательными полными декодированиями FFmpeg, аудиодорожки нет.
- Встроенный тест видео и music player разделены; в коде видеопути нет запроса audio focus и нет вызова перезапуска музыкального плеера при цикле.
- По умолчанию полноэкранное заполнение. На физическом Яндекс ТВ требуется проверить запуск аппаратного декодера, полноэкранность, стык цикла, музыку и заставку. Факт использования аппаратного overlay в этой среде не наблюдался.
