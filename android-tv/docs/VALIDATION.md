# Проверка 0.4.0 · build 5

Автовыбор разрешения TV для orbital-port и sunken-teahouse.
Full HD/HD-ready: desktop_1920x1080. 4K: desktop_3840x2160.
Используются физические Display.Mode, не размер интерфейса Android.
При равном размере выбирается частота, ближайшая к текущей. Максимум 4K.
Готовность родного формата проверяется на каждом цикле current.json;
если он не готов, используется другой готовый TV-профиль 16:9.

61 проверка на JDK прошла: физические режимы Full HD и 4K, 1080p UI при
4K-режиме, разные частоты, выбор обеих тем, переход с временного профиля
на родной без обновления каталога, отсутствие готовых профилей, неверные
размеры/коллекция, существующие протокол/погода/расписания/долгий OK/кеш.

32 проверки на Android TV API 28, 1920×1080, прошли. Проверены новая
установленная версия; реальное определение Full HD экрана; обе темы при
выборе Full HD и 4K; старые дескрипторы и настройки звука; живая загрузка
текущего опубликованного 4K кадра Орбиты как временного профиля на Full HD;
SHA-256, Android-декодирование с уменьшением и повторное использование
кеша; готовность TV-чайной; декодирование экспортированного Full HD JPEG
из тестового пакета; приоритет кеша Full HD перед кешем 4K.

Full HD публикация ещё не размещалась на сервере этим заданием.
Её файл проверялся как тестовый JPEG, не как существующий публичный URL.
Контракт source theme 0.2 остаётся прежним; новые API не вводятся.
