# Интерфейс TV 0.7.0 — проверка выпуска

Основное меню содержит выбор обоев, музыку текущей коллекции и настройки. Очистка находится в Настройки → Хранилище; обновление приложения и диагностика — в О приложении.

Выбор обоев проверен на реальном Android UI эмулятора API 28 с логическим экраном 960×540. Превью и краткое описание находятся рядом со списком коллекций. Фокус не применяет коллекцию; OK применяет и закрывает панель. Кадр выбранной коллекции проверяется в рендерере, а не только по сохранённой настройке. Длинное обозначение «194x / 19XX» не разрывается. Прокрутка имеет мягкие края; фокус и позиция сохраняются после возврата из других экранов и после Home.

Автономно пройдены 215 проверок. В Android пройдены 52 проверки: короткий/долгий OK, D-pad, три основных действия, вложенные экраны и Back, громкость, независимые режимы музыки, превью, применение коллекции, Home/возврат, QR-ссылка и сведения о музыке, очистка с сохранением параметров. Отдельно проверено декодирование обоих QR-кодов, в том числе GitHub-кода со снимка экрана.

Во время просмотра снимков найдена задержка сохранённого кадра за старым сетевым запросом. Для декодирования кеша выделена независимая очередь. Превью использует её же, чтобы отменённая загрузка промежуточной коллекции не задерживала сохранённое изображение следующей. Новое сетевое состояние имеет приоритет над запоздавшим результатом кеша.

Полный прогон и параметры APK записаны в VALIDATION_0.7.0.json. Снимки интерфейса находятся в qa/0.7.0/. Сцены в тестах подготовлены из сохранённых изображений: это доказательство состояния UI, а не проверка живой публикации тем. Работа физического Яндекс ТВ, аппаратного HEVC 4К, реального аудиофокуса ТВ и системной установки обновления этим прогоном не подтверждается.
