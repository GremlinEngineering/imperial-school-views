Реализовано в 0.5.0 / build 10

Любая динамическая тема с опубликованным desktop_3840x2160 3840×2160 и корректным блоком video. Имя коллекции не определяет поддержку.

Независимая равномерная случайная проверка JSON каждые 600–1200 секунд. Неподготовленная публикация опрашивается с обычным интервалом. Ошибки сети используют прежний ретрай приложения 1–5 минут; внутри сбоя MP4 сначала повторно читаются актуальные JSON, затем качается указанный в них файл с начала. Частичные файлы удаляются.

Совпавший SHA-256 не вызывает повторного скачивания, смены декодера или музыки. Метаданные и актуальность обновляются отдельно. Следующий новый MP4 полностью проверяется и подготавливается до смены текущего. Однокодековый путь сохранён для одинакового CSD/FPS и достаточного входного буфера; иначе требуется переинициализация с прежним Surface.

Кеш 64 МиБ. Старый и подготовленный локальные файлы защищены до передачи владения. На сервере предыдущие ролики не требуются: удалённый URL приводит к обновлению JSON и ретраю.

Просрочка: stale_after = at + 2 * (valid_until - at). Часовой кадр — два часа от at. После порога последний исправный кадр не убирается с экрана. Тот же MP4 при свежем JSON обновляет актуальность без загрузки.

Музыка приложения и заставки отдельно, выбирается по текущей теме. Плашек поверх картинки нет. Параметры находятся в «Состояние и кеш».
