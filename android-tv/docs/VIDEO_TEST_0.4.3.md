# 0.4.3 · build 8

Встроенный образец заменён на кадр по утверждённому эскизу. Земля с облаками и атмосферой, звёзды, станция, осенняя оранжерея, шесть кораблей. Это фиксированный художественный тест воспроизведения, а не серверный актуальный кадр и не анимация движения сцены.

Удержать OK → «Вывод через видео» → включить. Видео должно заполнить экран и повторяться каждые 4 секунды. Музыка воспроизводится независимым плеером; звук приложения и заставки настраиваются отдельно. Выключение видео возвращает обычные обои.

На телевизоре проверить: запуск аппаратного HEVC, заполнение экрана, стык цикла, непрерывность музыки и выход/вход в заставку. Наличие аппаратного overlay требует наблюдения на самом устройстве.
