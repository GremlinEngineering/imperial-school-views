# Проверка 0.3.1 · build 4

Дата: 4 ноября 2026. Автор: Дмитрий Малыхин aka Timon_Crazy.

Изменение касается TV-клиента: `orbital-port` и `sunken-teahouse` используют
именно `desktop_3840x2160`, 3840×2160, 16:9. Старый каталог и сохранённый
дескриптор не переключают их на Mac, 16:10 или ultrawide.

Официальные Platform 36 / Build Tools 36.0.0, JDK 21. Компиляция, D8,
zipalign, подписи v2/v3 прошли. Package ID прежний:
`ru.oopssre.imperialschool.viewstv`, minSdk 26, targetSdk 36.
APK: `ImperialSchoolViewsTV_0.3.1.apk`, 17791613 байт.
SHA-256: `65946a1d2e2348d892ffe32d239ebb6bdc738c976988fe670c8bb9ad71e586cd`.
Сертификат SHA-256:
`67e2174516f404553dce739f482e87251f464c300a29d35789a9fb6e8bfbeeb5`.
Версия 0.3.1 / build 4; подпись прежняя. Release JSON сверён с APK.

46 автономных проверок прошли. Использованы реальные JSON опубликованной
«Орбиты»; существующие desktop/Mac JSON чайной проверены как неподходящие для TV. Дополнительно проверены миграция старых дескрипторов обоих TV-профилей,
отказ от подстановки другого профиля чайной и сохранение выбора других коллекций.

На Android TV API 28, 1920×1080: **23 проверок прошли**.
Проверены версия установленного APK, оба точных TV-устройства при старом
каталоге и сохранённом выборе, сохранение звуковых настроек, реальная загрузка
JPEG «Орбиты» с сервера, SHA-256, размеры и декодирование Android, повторное
использование кеша, готовность TV-чайной и сохранение выбора устройства. Лог: `qa/tv4k-0.3.1.txt`.

TV-публикация чайной готовится отдельно. До её готовности клиент ждёт
`dynamic/sunken-teahouse/devices/desktop_3840x2160/current.*` и не заменяет
кадр версиями для Mac или 16:10. После появления готовой публикации
приложение получает её своим штатным циклом обновления.

Сетевой прогон эмулятора использовал прокси среды проверки. Его публичный CA
добавлен только в процесс инструментального теста; production APK, системные
проверки сертификата и имени сервера не изменялись.
Проверка запуска сцены на свежем эмуляторе остановилась на нативном сбое
его графического драйвера gralloc.ranchu / QemuPipeStream при lockCanvas.
Этот прогон не считается успешной проверкой отрисовки. Код SurfaceView
не менялся в 0.3.1; предыдущие UI/remote проверки относятся к 0.3.0.

Физический Яндекс ТВ и системный запуск DreamService прошивкой не проверялись.
Музыка, её 16 файлов, два флага звука и обработчики жизненного цикла не менялись.
Предыдущие аудио/визуальные проверки версии 0.3.0 сохранены в
`VALIDATION_0.3.0.md`; они не выдаются за повторный прогон на 0.3.1.
Пакет сайта подготовлен для ручной публикации. Сервер не изменялся.
