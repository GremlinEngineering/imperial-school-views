# Сверка оформления с сайтом

Дата: 4 ноября 2026. Принятая иконка «телевизор + геймпад» сохранена.

Основа — действующий `https://games.oopssre.ru/assets/style.css` и эталон бренда существующего Android-клиента. SHA-256 CSS: `8140886cac1c6bc181b7ade1d83369dac25258e8cc09b40ca1ca26bfc0c96ed0`. Снимок сохранён рядом в `site-style-reference.css`.

Кнопка в фокусе получает сплошной золотой фон и тёмный текст. Это адаптация акцентного оформления для навигации с пульта: положение фокуса видно с расстояния. Размер кнопки не меньше 56 dp, основной текст управления 20 sp. Настройки открываются справа поверх сцены, обычный запуск оставляет весь экран обоям.

Исправления по проверке:

- Удалён бирюзовый акцент промежуточного макета, использован золотой цвет сайта.
- Подключены шрифты сайта; баннер Android TV также оформлен Oswald и Literata.
- Сохранена принятая иконка, без гаечного ключа.
- Исправлена начальная прокрутка раздела «О приложении»: при входе виден заголовок.
- Автор, проект, установленная версия и сайт находятся в «О приложении»; параметры кадра и кеша перенесены в отдельный раздел «Состояние и кеш».
- Служебное имя файла обновлений убрано из пользовательского описания.

Проверка выполнена по настоящим снимкам интерфейса Android TV, а не по нарисованному макету. Снимки и результат инструментальной проверки находятся в `qa/`. Эмулятор: Android TV API 28, 1920×1080, density 320. Проверка на физическом 55-дюймовом Яндекс ТВ в эту поставку не входит.

Итоговая ручная проверка трёх снимков: заголовки и основной текст видны, фокус различим; в «О приложении» версия, проект, автор и адрес сайта помещаются в исходной области просмотра. Длинные списки прокручиваются с пульта.
