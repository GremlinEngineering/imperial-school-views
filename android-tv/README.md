# Виды и обои · Android TV

Русский · [English](README.en.md) · [О проекте](../README.ru.md)

Версия **0.6.0**, сборка **11**. Android TV / Яндекс ТВ, Android 8.0+ (API 26), пакет `ru.oopssre.imperialschool.viewstv`.

Приложение показывает коллекции «Школы Империи» на телевизоре и работает системной заставкой Android. При запуске сразу открываются обои. Динамические сцены поступают готовыми с сервера; слои на телевизоре не собираются.

## Возможности

- Обычные, погодные и динамические коллекции, PNG и JPEG.
- Серверное видео HEVC 3840×2160 для динамических тем.
- Выбор разрешения картинки: Авто, 4К или Full HD; вписывание или заполнение экрана.
- Серверная погода и погода игрового мира; расписание смены обычных обоев.
- Независимые настройки звука приложения и заставки, громкость и переключение треков.
- Показ объёма и очистка кеша с сохранением выбранной темы и настроек.
- Сохранение последнего проверенного кадра или ролика при ошибке обновления.

## Использование

Удерживайте OK **одну секунду**, чтобы открыть настройки. Стрелки перемещают фокус, короткий OK выбирает пункт. «Назад» возвращает на предыдущую страницу, из настроек — к обоям, из показа — выходит из приложения. После возврата из подменю сохраняются фокус и положение списка.

В **Обоях** выберите коллекцию, в **Экране** — способ показа, разрешение и масштаб. Погодные и обычные коллекции показываются картинкой; выбранный видеорежим сохраняется для динамических тем.

В **Музыке** доступны звук приложения и заставки, громкость, предыдущий и следующий трек. Меню появляется у коллекций с музыкальным набором. Сведения об авторах находятся в **О приложении → Музыка и авторы**, технические данные — в **Диагностике**.

В **Кеше** показаны общий объём, обои и скачанный файл обновления. Очистка удаляет кешированные кадры, ролики, метаданные и установщик обновления, затем загружает текущую сцену заново. Выбор темы, разрешение и настройки музыки сохраняются.

Для системной заставки откройте соответствующий пункт настроек и выберите приложение средствами Android. Нажатие стрелки завершает заставку.

## Данные и обновления

Обои хранятся в частном кеше с лимитом **64 МиБ**. Архивы коллекций и будущие кадры не скачиваются. При сбое сети остаётся последний проверенный кадр или ролик.

Новый ролик загружается и проверяется, пока предыдущий продолжает играть, затем сменяется на границе цикла. Видео поддерживается у динамических тем с опубликованным профилем `desktop_3840x2160` и блоком `video`. Если ролик ещё не опубликован, можно выбрать показ картинки.

В комплекте приложения — семь музыкальных фрагментов станции и девять фрагментов чайной. Позиции плейлистов сохраняются отдельно. У коллекций без музыки воспроизведение останавливается. Громкость приложения не меняет системную громкость телевизора.

Обновление приложения проверяется кнопкой в настройках. Перед установкой проверяются пакет, подпись и контрольная сумма, затем открывается системный установщик Android.

## Сборка

Нужны Python 3, JDK 17+, Android SDK Platform 36 и Build Tools 36.0.0. Gradle не требуется.

Перед сборкой и тестами скопируйте зависимости и ресурсы из `ImperialSchoolViewsTV_0.6.0_source.zip` с сохранением относительных путей. Список файлов и контрольных сумм — [BINARY_RESOURCES.json](BINARY_RESOURCES.json).

Из корня репозитория:

```sh
cd android-tv
export ANDROID_HOME=/path/to/android-sdk
export IMPERIAL_TV_KEYSTORE=/private/path/imperial-tv.p12
export IMPERIAL_TV_PASSWORD_FILE=/private/path/password.txt
python3 build.py
```

Для самостоятельной сборки используйте собственный ключ с alias `tv` и файл пароля вне репозитория. Такая сборка не обновляет официальное приложение, подписанное другим ключом.

В `dist/` появляются APK, `android-tv-release.json` и пакет для сайта. APK универсальный, без зависимости от Google Play Services.

## Для сайта

Пакет `ImperialSchoolViewsTV_0.6.0_site.zip` содержит APK и `android-tv-release.json` в корне. Распакуйте их в действующий `views.root/installers/`, затем выполните обычную сборку сайта. Телефонный `android-release.json` остаётся отдельным файлом.

Готовые установщики распространяются на [сайте проекта](https://games.oopssre.ru/gremlin.html#views).
