## Что изменилось

- PNG и JPEG принимаются для динамических, погодных и обычных обоев. Формат, адрес, размер, SHA-256 и геометрия проверяются. PNG сохраняется и читается как PNG, без перекодирования в JPEG.
- Для динамики первичен `state.image`; альтернативный `compatibility_image` остаётся отдельным JPEG для сайта. Его хеш не заменяет хеш PNG при проверке кадра или `video.source_image_sha256`.
- Все три группы коллекций доступны при любом режиме вывода. В 0.5.0 глобальный видеофлаг скрывал погодные и обычные коллекции. Теперь это предпочтение видео для динамических тем: погодные и обычные показываются картинкой, а возвращение к динамической теме сохраняет выбор видео.
- Повреждённая или неподходящая отдельная запись каталога не скрывает остальные коллекции.
- Настройки сгруппированы по пользовательским задачам. Технические тексты, Surface, декодер и служебные идентификаторы доступны только в «О приложении → Диагностика».
- В музыкальном меню — независимые переключатели звука приложения/заставки, громкость, предыдущий/следующий трек, название и состояние. Описания синтеза и атрибуция доступны отдельно в «О приложении → Музыка и авторы».
- В меню «Кеш» показаны общий объём кеша приложения, обои (лимит 64 МиБ) и файл обновления. «Очистить кеш» удаляет картинки, MP4, JSON, временные файлы и скачанный APK обновления. Выбор темы, разрешение и настройки музыки сохраняются. Затем запрашивается текущая сцена заново.
- Перед очисткой отменяются загрузки, останавливается декодер и дожидаются завершения их рабочих очередей. Активные видеопины дополнительно запрещают небезопасную очистку. При обычной загрузке текущие JPEG/PNG/MP4 по-прежнему защищены от LRU-удаления.

## Пульт и меню

- Удерживать OK **одну секунду** — настройки. Короткий OK в сцене ничего не меняет.
- Стрелки — перемещение по пунктам, короткий OK — действие.
- «Назад» — предыдущая страница; из настроек — к обоям, из показа — выход.
- После возврата из подменю восстанавливаются фокус и положение списка.
- Стрелка в системной заставке завершает её, как и в предыдущей версии.

Настройки: **Обои**, **Экран**, **Музыка** (при наличии набора), **Кеш**, **Системная заставка**, **Обновление приложения**, **О приложении**, **Вернуться к обоям**. Для погодных коллекций дополнительно доступен источник, для обычных — расписание смены.

В «Экран»: способ показа динамических обоев, разрешение картинки Авто/4К/Full HD, вписать/заполнить и обновление обоев. Ручной выбор разрешения сохранён. Диагностика отдельно показывает размер файла, изображения в памяти, фактического Surface и видеодекодера.

## Видео, сеть и музыка

Сохранён видеоконтракт 0.5.0: любая динамическая тема с опубликованным `desktop_3840x2160` и корректным блоком `video`. Имена тем не определяют поддержку видео. HEVC 3840×2160 выводится аппаратным MediaCodec в SurfaceView; программного или скрытого 1080p-понижения нет. При отсутствии видео показывается ожидание его публикации; пользователь может выбрать картинку.

Новый MP4 загружается целиком, проверяется и подготавливается, пока предыдущий играет; затем подменяется на границе цикла. Сохраняются пути по SHA-256, повторное получение JSON после ошибки загрузки, условные HTTP-запросы, случайный опрос видео каждые 10–20 минут и отметка просрочки после двух TTL. Смена одного хеша обновляет метаданные без перезапуска музыки и декодера.

Обои загружаются только в ограниченный частный кеш. Архивы коллекций и будущие кадры не скачиваются. При сбое остаётся последний проверенный кадр/ролик. Android может удалить кеш самостоятельно.

Музыка — отдельный MediaPlayer. Сохранены все 16 прежних MP3 и независимые позиции плейлистов: семь FM-записей станции и девять SNES-фрагментов чайной. Звуковые файлы не менялись. Встроенных MP4 нет. У коллекции без музыки воспроизведение останавливается. Громкость приложения не меняет системную громкость ТВ.

## Установка и стандартный пакет для сайта

Package ID: `ru.oopssre.imperialschool.viewstv`. Подпись прежнего издательского ключа сохранена.

`ImperialSchoolViewsTV_0.6.0_site.zip` содержит в корне **только**:

- `ImperialSchoolViewsTV_0.6.0.apk`
- `android-tv-release.json`

Распаковать в действующий `views.root/installers/`:
`/var/sync/Game/01 - Played Games/editorial/wallpapers/views/installers/`, затем запустить обычную сборку сайта. Телефонный `android-release.json` не заменять.

Входной JSON — прежняя плоская build receipt: `schema`, `app_id`, `platform`, `version`, `build`, `bytes`, `sha256`. Публичные URL и конверт релиза формирует штатный сборщик. Само приложение проверяет обновление по кнопке, проверяет подпись/пакет/хеш/размер и открывает системный установщик Android.

## Сборка

Нужны Python 3, JDK 17+, Android Platform 36 и Build Tools 36.0.0. Gradle не требуется. Перед сборкой восстановить ресурсы и vendor JAR по списку выше.

```sh
export ANDROID_HOME=/path/to/android-sdk
export IMPERIAL_TV_KEYSTORE=/private/path/imperial-tv.p12
export IMPERIAL_TV_PASSWORD_FILE=/private/path/password.txt
python3 build.py
python3 test.py
```

Ключ и пароль в исходники не включены. APK универсальный, без нативных библиотек и зависимости от Google Play Services. Лицензия кода — MIT; сторонние компоненты и музыка сохраняют собственные лицензии.
