# Виды и обои · Android TV

Русский · [English](README.en.md) · [О проекте](https://github.com/GremlinEngineering/imperial-school-views)

Версия **0.8.8**, сборка **22**. Android TV / Яндекс ТВ, Android 8.0+ (API 26), пакет `ru.oopssre.imperialschool.viewstv`.

Приложение показывает авторские коллекции «Школы Империи» на телевизоре и работает системной заставкой Android. Если при запуске готового кадра ещё нет, сразу открывается меню. Когда кадр появится, открытое меню остаётся на экране. Готовые динамические сцены приходят с сервера; слои на телевизоре не собираются.

## Управление

Удерживайте OK **одну секунду**, чтобы открыть меню. Короткий OK во время показа не меняет сцену. Стрелки перемещают фокус, OK выбирает пункт. «Назад» возвращает на предыдущую страницу или закрывает главное меню. На экране обоев нажмите «Назад» дважды в течение двух секунд, чтобы выйти. Фокус и прокрутка сохраняются.

В основном меню — **Выбрать обои**, **Музыка** (у коллекций со звуком) и **Настройки**.

В выборе обоев слева показаны превью и краткое описание, справа — коллекции. Перемещение фокуса показывает превью, OK применяет коллекцию и закрывает меню. Группы «Живые сцены», «Погода» и «Коллекции изображений» доступны при любом способе показа. Внизу списка — параметры текущей погодной или обычной коллекции: источник погоды либо расписание смены.

В **Музыке** можно выбрать станцию темы или переключать композиции пакета. После выбора станции открывается экран «Музыка» с фокусом на громкости. Стрелки влево и вправо меняют громкость приложения. Переключатели звука для приложения и заставки независимы. Сведения о композициях доступны в «О приложении → Музыка и авторы».

При установке из заставки приложение закрывает её перед открытием установщика. На версиях 0.8.6 и 0.8.7, если окно установки скрыто заставкой, выйдите из неё после нажатия «Установить».

## Настройки

- **Показ изображения**: способ показа динамических обоев, Авто / 4К / Full HD для изображений, вписать / заполнить, ручная проверка обновления сцены.
- **Системная заставка**: настройки Android для выбора приложения в качестве заставки. Стрелка в самой заставке завершает её.
- **Прокси** — SOCKS5 или HTTP с отдельными переключателями для радио и других внешних подключений.
- **Хранилище**: общий объём, обои и превью, файл обновления; очистка с сохранением выбора и настроек.
- **О приложении**: автор, версия, сайт, исходный код, обновление приложения, музыка и диагностика. Для сайта и GitHub есть QR-коды и текстовые адреса.

При выборе видео приложение сначала проверяет наличие опубликованного ролика и заявленную аппаратную поддержку HEVC 4К. Пока доступность не подтверждена, действие недоступно и показана причина. Эта проверка не заменяет фактическое воспроизведение на устройстве. Автоматического скрытого переключения на изображение или программного понижения до 1080p нет.

## Сцены, сеть и хранение

Поддерживаются PNG без JPEG-перекодирования, JPEG и серверное HEVC-видео 3840×2160. Для видео используются опубликованный профиль `desktop_3840x2160` и блок `video`, без списка разрешённых тем. Новый ролик скачивается и проверяется, пока предыдущий играет, затем подменяется на границе цикла. При сетевой ошибке сохраняется последний проверенный кадр или ролик.

Произвольный общий лимит 64 МиБ удалён. Кеш сохраняет последние снимки коллекций и профилей, текущие и подготовленные файлы. Перед записью устаревшие файлы удаляются; при нехватке места дополнительно освобождаются старые неиспользуемые кадры. Проверяется реальное свободное место файловой системы. Во время декодирования изображения и подготовки/показа видео файлы защищены от удаления. Предельный размер отдельного сетевого изображения или ролика остаётся 32 МиБ.

Превью загружается только для коллекции в фокусе после короткой задержки, без скачивания архива и будущих кадров. Используется общий проверяемый кеш. Очистка дожидается освобождения загрузчиков, превью и декодера, удаляет кеш, затем заново запрашивает выбранную сцену. Android может очищать кеш самостоятельно.

Музыкальные пакеты тем загружаются с сайта и хранятся в кеше. Скачанные композиции доступны без сети. Для интернет-радио используется AndroidX Media3.

## Сборка и поставка

Текущая сборка воспроизводится по [исходникам исправления 0.8.8](releases/0.8.8/README.md) с официальным APK 0.8.7 в качестве входа. Java-проект, `build.py`, `test.py` и `BINARY_RESOURCES.json` в этом каталоге относятся к 0.7.0.

`ImperialSchoolViewsTV_0.8.8_site.zip` содержит APK и `android-tv-release.json`. Распакуйте оба файла в `views.root/installers/` и запустите обычную сборку сайта.
